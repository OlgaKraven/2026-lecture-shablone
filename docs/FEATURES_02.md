# Работа с возможностями 0.2

## Подготовка курса

Нажмите «Вход» в каталоге и введите логин и пароль редактора. После закрытия редактора или перезагрузки нужно войти снова. Все изменения остаются локальным черновиком до экспорта; опубликованный файл не изменяется из браузера. Настройте дисциплину и версию, добавьте лекции и слайды, заполните литературу, термины и карту соответствия РПД. Предпросмотр использует тот же компонент слайда, что показ аудитории.

Четыре типа заданий редактируются формами. Образец инфографики можно выбрать из курса, а её поля — изменить в расширенных параметрах слайда. Там же доступны дополнительные параметры, отсутствующие в простой форме. Проверка не позволяет выгрузить некорректную структуру. Семантическую правильность объяснений и соответствие РПД проверяет преподаватель.

Черновик автоматически сохраняется в браузере с историей до 30 состояний. Для переноса на другой компьютер скачайте черновик. Импорт сначала показывает версию и количество материалов, затем требует нажатия «Применить импорт». Изменение можно отменить. При импорте отдельного course.json загрузите соответствующий банк самопроверки отдельной кнопкой.

Для публикации скачайте course.json и assessment.json. Замените файлы в public (сохраните путь банка, заданный в assessment.url), выполните проверки и сборку. Обновляйте contentVersion при изменении содержания или ключей. Браузер не публикует файлы автоматически.

## Готовность и занятие

«Инструменты курса → Готовность» показывает незаполненные разделы. «Проверить файлы и возможности» проверяет доступность ресурсов и банка ответов, поддержку fullscreen, защиты ведущего и офлайн-копию. Проверка второго окна выполняется отдельной кнопкой, поскольку браузер требует непосредственного действия пользователя.

Проверка файла сценария читает локально выбранный JSON, проверяет версию и наличие сценария каждого слайда. Файл не отправляется на сервер. Физический проектор и перенос окна на второй монитор необходимо проверить на рабочем месте.

В панели преподавателя время разделов рассчитывается по estimatedSeconds в заметках (по умолчанию две минуты на слайд). Таймер перерыва приостанавливает основной таймер. После перерыва продолжите его вручную. Отставание считается относительно плановой длительности слайдов до текущего включительно; при нелинейном показе это ориентир.

## Инфографика и мобильные тесты

Библиотека поддерживает 18 вариантов данных. Блоки рассчитывают высоту по тексту; длинные слова переносятся. Кнопка «Рассмотреть схему» открывает крупный векторный рисунок. На телефоне схема представлена читаемыми карточками, таблицами и явными подписями связей; исходный рисунок остаётся доступен в крупном просмотре.

На ширине до 820px правильный ответ, объяснение и разбор не рендерятся в интерфейсе задания и результатов, включая изменение ширины открытого окна. Статус, баллы, список результатов и повторная попытка также скрыты. Правило относится к интерфейсу; автономные ключи остаются публичными файлами, как и в предыдущей версии.

## Самостоятельное изучение

Под слайдом доступны «Изучено», «Повторить», «Закладка». Раздел «Моё обучение» собирает отметки и ошибки самопроверки. Из задания с ошибкой можно перейти к ближайшему предшествующему объяснению. Это навигационная подсказка, а не автоматически установленная методическая связь; точные связи задаются в карте курса.

Каталог ищет по содержимому слайдов и предлагает прямые переходы. Глоссарий и карта программы показывают только материалы, заполненные автором. Официальные компетенции, источники и часы не генерируются автоматически.

## Резервные копии и версии

«Резервная копия» экспортирует настройки, отметки, позиции чтения и попытки текущей версии. Преподавательские сценарии, черновик редактора, данные других курсов и сеансов в неё не входят. Сценарий экспортируется отдельно в панели преподавателя.

Перед обновлением курса сохраните резервную копию и сценарий. При восстановлении копии другой версии сохраняются настройки и отметки существующих слайдов; позиция чтения — только если ID и содержимое слайда совпадают. Результаты старой версии пропускаются: ключи ответов могли измениться. Исходные данные старой версии не удаляются из браузера.

Импорт сценария другой версии показывает предупреждение и количество совпадающих ID. Заметки удалённых слайдов пропускаются. Совпадение ID не доказывает соответствия нового содержания старому сценарию — проверьте перенесённые заметки.

## Офлайн

Офлайн работает в собранной версии на HTTPS или localhost: npm run build, затем npm run preview. В режиме разработки sw.js не генерируется. Нажмите «Скачать курс для офлайн» и дождитесь сообщения об успешном сохранении. До этого готовность не подтверждается. Проверьте перезагрузку без сети до занятия.

В копию включаются файлы сайта, изображения, шрифты, инструкция, редактор, модуль двух окон и банк автономной самопроверки. Внешние сайты, ссылки литературы и папка материалов не скачиваются. Внешние ресурсы оформления должны разрешать CORS; если ресурс не удалось скачать, операция сообщает ошибку. Браузер может очистить кэш при нехватке места: проверяйте готовность перед занятием.

Сборка закрепляется до обновления service worker; изменение не подменяется в открытом занятии. Для обновления офлайн-копии завершите занятие, удалите прежнюю копию, закройте все вкладки этого сайта, откройте сайт с интернетом и скачайте курс заново. Отдельный npm-пакет движка не устанавливает service worker в чужом проекте: для него требуется свой шаг генерации sw.js по аналогии с scripts/build-offline.mjs.

## Проверки для автора

```sh
npm ci
npm run validate:content
npm run check:readiness
npm run test:unit
npm run lint
npm run build
npm run check:privacy
npm run build:engine
npx playwright install chromium firefox webkit
npm run test:e2e
```

Строгая готовность: `npm run check:readiness -- --strict`. Демонстрационные незаполненные разделы дают ненулевой код выхода в строгом режиме. Проверка сценария: `npm run check:readiness -- --teacher=private/my-notes.json`. Не помещайте сценарий в public.

GitHub Actions запускает технические проверки на push в main и pull request; публикация разрешена только вне pull request. Отчёт готовности демонстрации не блокирует сборку предупреждениями, но отсутствующие файлы и ошибки данных блокируют её.

## Границы выпуска

Хендбуки, импорт Java Notes.pdf и новый раздаточный формат в этот выпуск не входят. Сервер, личные кабинеты и централизованный сбор оценок не добавлялись. Существующая самопроверка остаётся автономным учебным режимом с публичными ключами.

## Вход, удаление и изображения

Вход ограничивает интерфейс локального редактора. GitHub Pages не выполняет серверную авторизацию: это не защита конфиденциальных данных от посетителя с инструментами разработчика. В public/editor-access.json хранится логин и PBKDF2-SHA256 проверочное значение с индивидуальной солью (210000 итераций); исходный пароль не включён в проект. При подключении движка к другому сайту настройте собственный editor-access.json в корне base. Пароль не записывается в черновик, резервную копию или хранилище браузера.

Выберите лекцию и нажмите «Удалить презентацию». Подтвердите удаление всех её слайдов; связанные ключи заданий и ссылки из глоссария и карты программы удаляются из черновика вместе с ней. «Отменить» восстанавливает прежнее состояние. В курсе остаётся минимум одна презентация. Публичный курс меняется только после экспорта и публикации.

В блоке «Изображение или скриншот» загрузите PNG, JPEG или WebP либо вставьте изображение из буфера кнопкой или Ctrl+V в отмеченную область. Входной файл — до 20 МБ; изображение уменьшается до 1920 пикселей и сохраняется в формате WebP внутри JSON курса (до 1 МБ на изображение). Заполните описание для доступности и подпись. Картинку можно заменить, удалить и восстановить через «Отменить»; она отображается в предпросмотре, слайде и печатной версии. Если браузеру не хватает места для черновика, скачайте его перед закрытием редактора.
Текстовое представление схемы открывается в отдельном окне. Крестик и кнопка «Закрыть» остаются вне прокручиваемой области; Escape закрывает окно и возвращает фокус к кнопке открытия. Внутри окна можно переключаться между рисунком и текстом.
