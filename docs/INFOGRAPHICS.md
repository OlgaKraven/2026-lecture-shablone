# Библиотека инфографики 0.2

В лекции VISUALS доступны 18 вариантов схем, включая timeline и три новых вида: layers, funnel, swimlanes. Данные отделены от векторного рендера; высота блоков и строк зависит от подписей. Длинные слова переносятся. Подписи связей вынесены в легенду. Цвет сопровождается текстом или номером.

На обычном слайде схема вписывается в доступное место. «Рассмотреть схему» открывает крупную версию с прокруткой, а «Текстовое представление» — полный структурированный текст. На ширине до 820px в обычном просмотре показывается читаемое представление: порядок этапов, ветви дерева, список связей, таблица или диаграмма. Векторная версия сохраняется в крупном просмотре, печати и окне аудитории.

| Вид | visual.type | Данные и ограничения |
|---|---|---|
| Последовательность | process | items: title, text; 2–8 этапов |
| Временная последовательность | timeline | items: title, text; 2–8 этапов, длительности задаются текстом |
| Развилка | decision | start, question, yes, no |
| Цикл | cycle | items: title, text; до 8 этапов; четыре этапа рисуются замкнутым контуром, остальные — с явным возвратом к началу |
| Сеть | network | nodes: id, title, text; edges: from, to, label; до 8 узлов и 12 связей; петли описываются отдельным циклом |
| Иерархия | tree | root, branches: title, items; до 6 ветвей по 4 листа |
| Сравнение | comparison | columns, rows; до 6 колонок и 8 строк |
| Матрица | matrix | columns, rows; до 6 колонок и 8 строк |
| До и после | beforeAfter | before/after: title, fields: label, value; changes |
| Карта понятий | conceptMap | center, items: title, example, relation; до 8 понятий |
| Состояния | states | states, cancelFrom; до 8 состояний, cancelFrom — индексы от нуля |
| Причина и следствие | cause | cause, effect, solution |
| Изображение с выносками | callouts | image, alt, items: x, y, title, text; до 6 отметок, координаты 0–100% области изображения |
| Разбор кода | codeParts | parts: code, label, explanation; до 8 фрагментов |
| Столбчатая диаграмма | bars | items: label, value; max, unit, threshold?; до 8 значений, ось от нуля |
| Слои архитектуры | layers | items: title, text; до 8 уровней ответственности |
| Воронка | funnel | stages: label, value, detail; unit; 2–8 этапов, значения не возрастают, первое больше нуля |
| Дорожки ответственности | swimlanes | lanes: title, steps: title, text; до 4 ролей по 5 действий |

Для всех видов обязателен caption с выводом и условиями. Количественные учебные примеры явно обозначаются как условные; реальные значения требуют источника. Максимальный размер структуры не является рекомендацией заполнять каждый слайд до предела: сложное объяснение лучше разделить на части. Редактор предоставляет образцы и проверку параметров, но методическую корректность проверяет автор.

Пример нового вида:

```json
{
  "type": "layers",
  "items": [
    {"title": "Интерфейс", "text": "Получает действия пользователя и показывает результат."},
    {"title": "Правила", "text": "Проверяет условия и выполняет сценарий."},
    {"title": "Данные", "text": "Сохраняет и читает записи."}
  ],
  "caption": "Учебный пример: каждый слой отвечает за собственную задачу."
}
```

Проверки включают границы SVG-текста для всех образцов и отсутствие горизонтального переполнения страницы на ширине 390px. Таблицы и крупные векторные схемы могут прокручиваться внутри своей области.
