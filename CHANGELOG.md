# История изменений

## 0.2.0 — 2026-09-12

- Расширенная инфографика: адаптивная высота блоков, крупный просмотр, мобильное текстовое представление; новые слои, воронка и дорожки ответственности. 86 демонстрационных слайдов, 18 вариантов схем, версия данных demo-3.
- На мобильных экранах до 820px скрыты правильные ответы и разборы, включая результаты и сужение уже открытого разбора.
- Полная структурная проверка поддерживаемых слайдов, инфографики, заданий, банков ответов, глоссария и карты программы. Ошибки содержат путь к полю.
- Отчёт готовности, проверка локальных файлов и отдельная проверка преподавательского сценария.
- Редактор локального курса: лекции, слайды, задания, литература, глоссарий, карта РПД, предпросмотр, автосохранение, история из 30 состояний, импорт с подтверждением, экспорт курса и ответов отдельно.
- Поиск по содержимому, закладки, отметки изучения и повторения, переход из ошибок к предшествующему объяснению.
- Резервные копии настроек и результатов с проверкой данных и предварительным просмотром восстановления. При смене версии оценки не переносятся; позиция чтения переносится только для неизменённых слайдов.
- Сценарии старой версии импортируются отдельно после предупреждения, только для существующих ID слайдов.
- Офлайн-копия всей сборки, включая динамические модули и банк самопроверки. Готовность подтверждается после загрузки всех файлов.
- План времени по разделам, предупреждение об отставании и таймер перерыва в панели преподавателя.
- Повтор загрузки курса после ошибки, защита при несохранённых заметках и черновике, экран восстановления при ошибке компонента.
- Браузерные тесты, проверки доступности, CI для pull request и сохранение существующего размещения на GitHub Pages.

Интеграция хендбуков и новый формат раздаточных материалов отложены по просьбе пользователя. Java Notes.pdf не импортировался.
